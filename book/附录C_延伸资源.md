## C.2 官方文档（查 API 用）

本书反复强调"**API 参数语义要讲透**"，但书里只能讲最常用的那几个。
真要查全，还是得看官方文档：

| 查什么 | 地址 |
|---|---|
| PyTorch 主文档 | <https://pytorch.org/docs/stable/index.html> |
| `torch.nn`（各种层） | <https://pytorch.org/docs/stable/nn.html> |
| `torchvision.transforms`（数据增强） | <https://pytorch.org/docs/stable/torchvision/transforms.html> |
| PyTorch 官方教程（60 分钟入门等） | <https://pytorch.org/tutorials/> |

**怎么读官方文档**：每个 API 页面最上面那段 `Parameters` 是最值钱的部分。
比如 `nn.Conv2d` 的 `padding` 参数，文档里写的是
"implicit paddings on both sides"—— 注意 **both sides**：
`padding=1` 是**左右各补 1 列、上下各补 1 行**，不是总共补 1。
这种细节书里讲了，但文档是唯一的权威。

<blockquote class="tip">

**💡 一个查文档的习惯**

看到不认识的参数，**先看它的默认值，再看它影响什么形状**。

拿 `nn.MaxPool2d` 举例（这是本书第 3 章用的）：

```python
nn.MaxPool2d(kernel_size, stride=None, padding=0, dilation=1, ...)
```

- `kernel_size` **没有默认值**，必须传 —— 光看名字可能以为它有
- `stride=None` 是**有意义的默认值**：文档里写"默认等于 `kernel_size`"

两条合起来才能解释"为什么 `nn.MaxPool2d(2)` 一个参数就够、尺寸正好减半"：
`kernel_size=2` 是你传的，`stride` 自动也是 2。**只看 `stride=None` 会以为它不动。**

</blockquote>

## C.3 实验室的下一个任务：PoolNet

- 代码库：<https://github.com/backseason/PoolNet>

这是任务书里排在本任务后面的内容 —— **池化方式的研究**。
本书第 8 章 §8.7 专门写了"怎么用到 PoolNet"，思路是：

| 第 8 章的哪个文件 | 到了 PoolNet 怎么用 |
|---|---|
| `config.py` | 加 PoolNet 自己的超参（池化方式、层数……），路径那一段原样照抄 |
| `model.py` | 换掉池化层，其余结构不动 |
| `dataset.py` | 大概率一个字都不用改 |
| `engine.py` | **一个字都不用改** |
| `train.py` | 换模型、换配置，流程不变 |

**这正是第 8 章存在的意义**：把"每次都一样的那部分"和"每次都变的那部分"分开。
写第一遍的时候多花 20 分钟拆文件，后面每个实验都省事。

<blockquote class="done">

**📌 你现在应该能做到的事**

跑完本书，你应该能独立完成这个动作：

> 拿到一个新的网络结构（比如 PoolNet），
> **知道要改哪个文件、不用改哪个文件**，
> 然后把它跑起来、看懂它的结果。

这比"背下多少个 API"有用得多。

</blockquote>

## C.4 地基：Python

如果你在读本书时觉得吃力的地方**不在深度学习，而在 Python 本身**
（比如看不懂 `@dataclass`、`*args`、列表推导、`with` 语句），
那说明该补的是 Python，不是 PyTorch。

本书用到但**不属于深度学习**的 Python 特性：

| 特性 | 用在哪 | 说明 |
|---|---|---|
| 模块与 `import` | 第 8 章整章 | 5 个文件互相 import，怎么组织 |
| `dataclass` | 第 8 章 `config.py` | 白送 `__init__` 和 `__repr__` |
| `argparse` | 每章脚本 | 命令行参数 |
| `pathlib.Path` | 每章脚本 | 路径拼接、跨平台 |
| 类与继承 | 第 2 章起 | `nn.Module` 子类 |
| 类型标注 | 全书 | `def f(x: int) -> str:` |
| f-string | 全书 | 打印格式 |
| 上下文管理器 `with` | 第 2 章起 | `torch.no_grad()` |

**这些一个都不熟也没关系** —— 本书正文里凡是第一次出现，都会顺带解释。
但如果**大部分都不熟**，建议先花一周过一遍 Python 基础，再回来。

<blockquote class="tip">

**💡 不用专门去学 NumPy**

有人会建议你先学 NumPy。**没必要。** 本书每个脚本确实都 `import numpy`，
但用到的只是一小把函数，全都属于"看名字就知道在干嘛"的水平：

| 用到的 | 干嘛用 | 本书哪几章 |
|---|---|---|
| `np.random.*` | 固定随机种子 | 全书 |
| `np.mean` | 算 MNIST 的均值（§1.5） | 第 1 章 |
| `np.concatenate` | 把各批的预测结果拼起来 | 第 7 章 |
| `np.zeros` / `np.arange` / `np.sort` / `np.trace` | 手写混淆矩阵、算指标 | 第 7 章 |

**要用到什么再学什么**，比先啃一遍库再回来更有效率。
真要看文档的话，遇到不认识的函数按名字猜一下再验证，基本都对。

</blockquote>
