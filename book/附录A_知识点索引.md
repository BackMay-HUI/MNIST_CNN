# 附录 A　知识点索引

这份索引解决一个问题：**实验室任务书列了 7 个知识点，它们在本书里分别在哪？**

本书是**按"从零搭一个模型"的顺序**写的（数据 → 全连接 → 卷积 → 增强 → 调参 → 正则化 → 评测 → 工程化），
不是按任务书的 7 条清单写的。两者能对上，但顺序不同、有的知识点分散在好几章。
所以先给一张总表，再逐个知识点说明"读到什么程度算过关"。

## A.2 逐个知识点

### ① 数据加载 —— 第 1 章

**核心问题**：怎么把一堆图片变成模型能吃的张量，并且分批喂进去。

| 要掌握 | 在哪 |
|---|---|
| `Dataset` 和 `DataLoader` 各管什么 | §1.2 |
| `ToTensor()` 做了三件事（缩放到 0~1 / 通道维提前 / 变成张量） | §1.4 |
| `Normalize` 那两个数（0.1307 / 0.3081）是 MNIST 的全局均值方差 | §1.5 |
| 为什么要切成训练 / 验证 / 测试三份 | §1.6 |
| `shuffle=True` 只给训练集 | §1.2、§1.7 |

**过关标准**：能自己写出"读 MNIST → 切分 → 包成 DataLoader → 取一个 batch 看形状"这四步，
并说得出 `x.shape` 的四个维度分别是什么。

<blockquote class="tip">

**💡 一个容易忽略的点**

`Normalize` 之后像素值**不再是 0~1**（会变成负数）。所以画图时必须用不带 `Normalize` 的
transform，否则 `imshow` 出来是一片灰。第 1 章 §1.5 专门讲了这件事。

</blockquote>

---

### ② 数据增强 —— 第 4 章

**核心问题**：训练集不够"难"时，怎么人工造出更多样本，逼模型抓本质而不是背题。

| 要掌握 | 在哪 |
|---|---|
| 增强 = 给训练集加难度 | §4.1 |
| **为什么只能对训练集做** | §4.2 |
| `transforms` 的顺序为什么不能乱 | §4.3 |
| **MNIST 上不能用翻转类增强**（翻转后标签就错了） | §4.3 |
| 三档增强的实测差距 | §4.4 |

**过关标准**：拿到任何一个增强手段，能先问一句"**变换之后标签还对吗？**" ——
这一问就能挡掉翻转、大角度旋转这类在 MNIST 上有害的操作。

<blockquote class="warn">

**⚠️ 别把增强当成"一定能涨点"的开关**

本书实测：轻增强 +0.43pp（落在噪声边缘），强增强 **−1.59pp**（明显变差）。
增强是**有代价的交换**（每个 epoch 耗时大约翻倍），不是免费的收益。详见 §4.4。

</blockquote>

---

### ③ 模型初始化 —— 第 3 章 §3.8

**核心问题**：权重一开始取什么值？取错了会怎样？

本章用四档初始化做了对照实测：

| 初始化 | 测试集 | 现象 |
|---|---|---|
| PyTorch 默认 | 98.80% | 正常 |
| Kaiming（He） | 98.43% | 正常 |
| **全 0** | **11.35%** | 完全学不动，10000 张全判成同一个类 |
| 正态 std=1.0 | 11.35% | 第 1 轮 loss 炸到 10¹⁵，然后塌进和全 0 一样的死状态 |

**要掌握的结论**：初始化要解决的不是"**要不要随机**"，而是"**方差该多大**"。
全 0 之所以死，是因为所有神经元永远算出同一个值（对称性无法打破）。

**过关标准**：知道 `nn.init.kaiming_normal_` 是干什么的、什么时候该用它，
以及"**别把权重初始化成全 0**"这条底线。

<blockquote class="tip">

**💡 说实话：浅网络上默认初始化和 Kaiming 差不多**

上面表里 98.80% 和 98.43% 的差距（0.37pp）**落在种子噪声带（0.43pp）以内**，
所以本书不会告诉你"必须用 Kaiming"。它真正的作用在网络变深以后才显现。
换成"用 Kaiming 更保险"来记就行 —— 别记成"用了就能涨点"。

</blockquote>

---

### ④ 模型构建 —— 第 2 章 §2.2 → 第 3 章 §3.3–3.6

**核心问题**：怎么用 `nn.Module` 描述一个网络。

| 要掌握 | 在哪 |
|---|---|
| `nn.Module` 子类只写两个方法：`__init__` 声明零件、`forward` 声明数据怎么流 | 第 2 章 §2.2 |
| 卷积的四个旋钮：`in_channels` / `out_channels` / `kernel_size` / `stride`+`padding` | 第 3 章 §3.3 |
| 池化 = 2×2 取最大，降尺寸、没有参数 | 第 3 章 §3.4 |
| **形状靠打印，不靠手算** | 第 3 章 §3.5 |

**过关标准**：改一个卷积层的参数之后，知道要去哪儿看形状对不对
（本书的做法是把每层形状打印出来，存进 `figures/ch03_shape_trace.txt`）。

<blockquote class="done">

**📌 本书的深度契约**

**不要求你会手算卷积输出尺寸，也不要求你推导反向传播。**
任务是"知道卷积在干嘛、会调 API"，所以形状一律靠 `print` 观察。

但**参数语义必须讲透** —— 因为调超参时你得知道拧每个旋钮会发生什么。
`kernel_size` 从 3 改成 5 会怎样、`padding=1` 是干嘛的，这些要清楚。

</blockquote>

---

### ⑤ 超参数调节 —— 第 5 章

**核心问题**：哪些数字是"人定的"？它们各自影响什么？

| 旋钮 | 在哪 | 本书的实测结论 |
|---|---|---|
| 学习率 `lr` | §5.1 | **唯一一个"调错就全完"的旋钮**：SGD 用 0.01，不是 1e-3 |
| `batch_size` | §5.2 | 同时影响准确率和速度，而且**方向相反** |
| 优化器 | §5.3 | **换优化器就要重想学习率** |
| 学习率调度器 | §5.4 | 一个诚实的"**没用**"（本书实测没涨点） |

**过关标准**：知道 `lr` 必须和优化器配套（SGD 用大学习率，Adam 用小学习率），
并且**任何小于噪声带（0.43pp）的差距都不能当结论**。

<blockquote class="warn">

**⚠️ 最省事的调参顺序**

先固定一组能跑通的配置（`lr=0.01` + `SGD` + `momentum=0.9`），
再**一次只动一个旋钮**。同时改两个，出了变化你说不清是谁的功劳。
详见 §5.5。

</blockquote>

---

### ⑥ 训练和测试 —— 第 2 章 §2.4–2.5

**核心问题**：怎么让模型把参数学出来，以及怎么正确地"考试"。

| 要掌握 | 在哪 |
|---|---|
| 训练循环五步：`zero_grad → forward → loss → backward → step` | 第 2 章 §2.4 |
| **梯度是累加的，所以 `zero_grad()` 不能省** | 第 2 章 §2.4 |
| `model.train()` / `model.eval()` 和 `no_grad()` 是两件独立的事 | 第 2 章 §2.5 |
| `CrossEntropyLoss` 吃的是 **logits**，前面别加 softmax | 第 2 章 §2.6 |
| early stopping 与 checkpoint | 第 5 章 §5.6 |

**过关标准**：能默写出这五步，并且知道自己为什么在评估时要写
`model.eval()` + `torch.no_grad()`。

<blockquote class="warn">

**⚠️ 验证集和测试集不是一回事**

- **验证集**：训练过程中用它做**所有决定**（选超参、早停、挑模型）——
  你"看过"它了
- **测试集**：全程不碰，只在最后汇报一次

**凡是影响过你决策的数字，都不能再当最终成绩。** 详见第 1 章 §1.6 和第 7 章 §7.8。

</blockquote>

---

### ⑦ 模型性能测试 —— 第 7 章

**核心问题**：98.62% 这个数字够不够说明问题？不够的话还该看什么？

| 指标 | 在哪 | 回答什么问题 |
|---|---|---|
| 准确率 | §7.1 | —— 整体的，会被类别不平衡掩盖 |
| 精确率 / 召回率 / F1 | §7.2 | "**看列还是看行**"的区别 |
| 混淆矩阵 | §7.3 | 错在**哪两个类之间** |
| 每类准确率 | §7.4 | 短板是哪个类 |
| 错例可视化 | §7.5 | 模型到底错在哪张图上 |
| 置信度 | §7.6 | 错得**自不自信** |
| 特征可视化（t-SNE） | §7.7 | 模型"眼里的世界" |

**过关标准**：知道准确率不够用，至少会看**混淆矩阵 + 每类准确率**这两样。

<blockquote class="done">

**📌 本书实测的结论（可以直接引用）**

测试集 98.62%，最弱的是「**6**」（97.18%），最大的混淆对是「**6 → 5**」（12 张）。
最强的「0」是 99.39%。**注意逐类指标的噪声带比整体宽（~1pp）** ——
因为每个类只有 900~1135 张测试图，样本少、波动大。

</blockquote>

第 6 章（正则化）和第 8 章（工程结构）可以后面再看 ——
